# 备考资料库（resources/）

本目录收录**中山大学《军事理论》课程**的备考资料原件，与项目根目录的模考系统配套使用。

> 📦 **总量**：58 个文件 / 112.6 MB
> 🔗 **来源**：由 [`scripts/upload_resources.py`](../scripts/upload_resources.py) 从本地资料目录递归同步而来
> 📋 **完整清单**：见 [`reports/upload-success.md`](../reports/upload-success.md)

---

## 📁 目录结构说明

同步脚本采用**保留原有相对目录结构**的策略，而非平铺合并。

### 为什么保留目录结构

| 考量 | 平铺合并 | 保留结构（采用） |
| :--- | :--- | :--- |
| 同名文件 | ❌ `2021A.pdf` 等极易冲突，后传覆盖先传 | ✅ 路径天然唯一 |
| 可追溯性 | ❌ 丢失"这份资料来自哪个分类" | ✅ 保留题库/课本/知识点等分类语义 |
| 可审计性 | ❌ 难以核对资料完整性 | ✅ 目录结构与来源一一对应 |
| 批量更新 | ❌ 难以按类别增量同步 | ✅ 可按目录粒度处理 |

资料本身存在同名不同内容的情况（如 `2021A.pdf` 与 `2021级军事理论a卷.pdf` 实为同一文件），
保留结构可让去重逻辑在路径层面就避免歧义。

| :--- | :--- |
| `军事理论A卷_FVUOEY.pdf` | 原始卷 |
| `军事理论A卷-解析版_FVUOEY.pdf` | 带答案解析 |
