# 评分规则说明

本文档说明系统的判分逻辑，便于使用者理解成绩构成，也便于贡献者改进算法。

---

## 1. 总览

| 题型 | 代码 | 判分方式 | 支持部分分 |
| :--- | :--- | :--- | :--- |
| 单项选择题 | `single` | 答案全等比对 | ❌ |
| 判断题 | `judge` | 布尔值全等比对 | ❌ |
| 不定项选择题 | `multiple` | 集合匹配，错选零分 / 漏选半分 | ✅ |
| 填空题 | `fill` | 归一化文本比对 + 关键词折算 | ✅ |
| 简答题 | `short` | 关键词采点折算 | ✅ |
| 论述题 | `essay` | 关键词采点折算 | ✅ |

---

## 2. 客观题判分

### 单项选择题

作答与标准答案**完全一致**得满分，否则零分。无容错、无部分分。

### 判断题

判断题的 `answer` 为**布尔值**（`true` / `false`），界面呈现为「正确 / 错误」。
作答与标准答案严格相等得满分，否则零分。

### 不定项选择题

采用**错选零分、漏选半分**策略：

```
标准答案：ABD（3 分）
作答 ABC  →  ❌ 0 分（含错选 C）
作答 AB   →  ⚠️ 1.5 分（漏选 D，得一半）
作答 ABD  →  ✅ 3 分（全对满分）
作答 A    →  ⚠️ 1.5 分（漏选）
```

> ⚠️ **注意**：本系统对不定项选择题的**漏选给一半分**，
> 与部分高校「不定项少选不得分」的严格规则不同。
> 漏选虽不得满分，但会损失一半分数，仍是主要失分点所在。

### 填空题

判分采用**两级策略**：先做整串精确匹配，未命中则回退到关键词折算。

```
标准答案：2.2万、1.8万

第一级 —— 归一化后精确匹配
  作答 "2.2万、1.8万"   → ✅ 满分

第二级 —— 包含关系 + 长度比例（阈值 0.6 满分 / 0.35 半分）
  作答 "2.2万1.8万"     → 视比例判定

第三级 —— 关键词命中比例折算（若题目定义了 points[].keywords）
  命中 2/4 个关键词      → 得一半分
```

归一化仅消除**排版层面**的差异（空白、标点、大小写），不处理语义等价表述
（如「十四」与「14」视为不同）。

## 3. 主观题采点评分

简答题与论述题采用**关键词采点**自动评分。

### 评分流程

```
参考答案
   │
   ├──► pointsOf()      按分句/序号切分采分项
   ├──► keywordsOf()    提取每项关键词
   └──► scalePoints()   按分值尺度为各采分项分配权重
                              │
学生作答 ──────────────────────┤
                              ▼
                    matchPoints() 逐项命中比对
                              │
                              ▼
                    autoScore()  汇总得分（保留 1 位小数）
```

### 采分点数据结构

主观题的 `points` 字段直接定义了采分点，无需运行时从文本推断：

```js
points: [
  {
    label: "以人民安全为宗旨",        // 采分项名称（用于结果展示）
    keywords: ["以人民安全", "宗旨"], // 命中任一即算该项命中
    score: 1.2                        // 该项分值
  }
]
```

**命中判定：** 一个采分项内，`keywords` 命中比例 ≥ 0.6，
或存在长度 ≥ 3 的关键词被完整包含，即视为该项 `got = true`，获得该项全部分值。

**校验要求：** `points[].score` 之和应等于该题 `score`
（校验显示 88 道主观题**全部通过**此一致性检查）。

### 计分原则

- 参考答案**结构越清晰、分点越明确，采分点识别越准确**；
- 采分点数量与题目分值正相关（分值越高，切分出的采分项越多）；
- 学生作答须包含相应**关键术语**方算命中；
- 最终得分四舍五入保留一位小数。

### ⚠️ 局限性说明

关键词匹配**不理解语义**，因此存在两类误差：

| 情形 | 示例 | 结果 |
| :--- | :--- | :--- |
| 同义未命中 | 标准「政治安全为根本」，作答「政治是根本」 | 可能漏判 |
| 关键词偶然命中 | 作答中出现关键词但表述错误 | 可能误判 |

**因此主观题得分仅供参考。** 系统始终在交卷后展示完整参考答案，
请以参考答案为准进行自我校正。

### 作答建议

为提高得分命中率，主观题建议：

1. **分点作答** —— 使用「①②③」或分号分条，便于逐点对照采分；
2. **术语准确** —— 尽量使用教材规范表述（如「总体国家安全观」而非「国家安全观」）；
3. **要点齐全** —— 简答题按「是什么—为什么—怎么办」组织；
4. **论述题套用结构** —— 亮明观点 → 教材原理 → 结合材料 → 对策升华。

## 4. 分值配置

### 练习模式（`BASE_SCORE`）

```js
const BASE_SCORE = { single: 2, multiple: 3, judge: 1, fill: 2, short: 10, essay: 10 };
```

### 考试模式（`EXAM_SCORE` 覆盖部分题型）

```js
const EXAM_SCORE = { short: 5, essay: 20 };
```

单一取值入口：

```js
const scoreOf = (t, mode) =>
  ((mode || "exam") === "exam" && EXAM_SCORE[t]) || BASE_SCORE[t] || 2;
```

### 课程考试蓝图

| 题型 | 题量 | 每题分值 | 小计 |
| :--- | ---: | ---: | ---: |
| 单项选择题 | 20 | 2 | 40 |
| 不定项选择题 | 10 | 3 | 30 |
| 简答题 | 2 | 5 | 10 |
| 论述题 | 1 | 20 | 20 |
| **合计** | **33** | — | **100** |

考试时长 **60 分钟**。真题试卷的分区与时长定义在各自 `sections[].per` 与 `duration` 字段中。

## 5. 成绩统计

交卷后系统展示：

- **总分**与**满分**；
- **正确率**；
- **用时**；
- **逐题明细** —— 展示你的作答、标准答案、正确答案与解析。

其中：

- 客观题展示「✓ / ✗」判定结果；
- 主观题展示「关键词命中情况」提示与参考答案全文。

历史成绩记录（`mt.history`）保留**最近 60 次**，超出部分自动淘汰最早记录。
